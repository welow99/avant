標榜（ひょうぼう）　ある主義・主張を掲げて公然と示すこと。「〜を標榜する」で「〜を看板として掲げる」というニュアンス。多くの場合、実態が伴っているかは留保しつつ使われる語で、やや批評的な距離感を含むことが多い。


補綴（ほてつ）　本来は欠けた歯を人工的に補う歯科用語(義歯やブリッジなど)。そこから転じて、欠損・不足している部分を継ぎ足して補うことを指す。文章や理論の「隙間を継ぎ接ぎで埋める」というイメージで、必ずしも美しい修復ではなく、応急的な継ぎ足しというニュアンスを帯びることもある。


端を発する　「端」は「はし・きっかけ・糸口」の意で、「〜に端を発する」で「〜を発端として起こる」「〜がきっかけで始まる」という意味の慣用表現

スティグマ


ある属性（肥満、不妊、HIV、性自認など）に対して、社会が共有・再生産する否定的な意味づけ（劣っている、恥ずべきである、望ましくないなど）。属性自体は本質的に中立だが、社会の期待（あるべき姿）と実際の属性とのギャップが、外部（メディア・制度・言説）によって否定的にコード化された状態を指す。


セルフスティグマ


そのスティグマを当事者本人が受容し、自分自身に対しても内面化してしまう現象・プロセス。「認知（ステレオタイプの存在を知る）→同意（それが正しいと考える）→適用（自分にも当てはまると考える）→結果（自己評価・自尊心の低下）」という段階を経て進行する。


| | 主体 | 性質 |
| -------- | ----- | ---------------------- |
| スティグマ | 社会・集団 | 属性に付与された否定的意味づけ（状態） |
| セルフスティグマ | 当事者本人 | その意味づけを内面化していく過程（プロセス） |
